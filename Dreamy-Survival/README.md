# Dreamy Survival 🌿

A separate Minecraft Bedrock resource-pack project, kept independent from the Android game in this repository.

## Style
Cozy Vanilla+ / cottagecore: soft natural colors, gentle greens, warm wood tones, and readable survival-friendly visuals.

## Status: starter scaffold
This commit adds the Bedrock resource-pack manifest and project notes only. It does **not** yet contain finished replacement textures or a tested `.mcpack` archive. No files from the existing Android game were deleted or modified.

## Target
- Minecraft Bedrock Edition
- Android
- Intended game version: 26.62 (verify pack compatibility in-game)

## Planned texture work
- Grass, leaves, flowers, and foliage
- Ores and stone
- Wood and common building blocks
- Friendly animal textures

Textures will be added in small, testable batches with the vanilla gameplay silhouettes and block readability preserved.
