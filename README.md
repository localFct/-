ЭХО: ЗА ГРАНЬЮ — Android Client 0.1.1

Это нативный Android-проект, НЕ готовый APK. В репозитории настроена облачная сборка APK через GitHub Actions, чтобы проект можно было собрать с планшета без установки Android Studio.

КАК ПОЛУЧИТЬ APK:
1. Откройте вкладку Actions в этом репозитории.
2. Выберите workflow “Build ECHO Android APK”.
3. Дождитесь завершения сборки со статусом Success.
4. Откройте запуск и скачайте artifact “ECHO-debug-APK”.
5. Внутри архива будет app-debug.apk — отладочная сборка для тестирования.

СОСТАВ:
- нативная Android Activity без Chrome/WebView;
- альбомная ориентация и полноэкранный режим;
- псевдо-3D raycasting и сенсорное управление;
- враги, три осколка, маяк, способности «ЭХО» и «Импульс».

ВАЖНО:
- APK ещё не собран; он появится только после успешного GitHub Actions.
- Это ранний игровой прототип с псевдо-3D, а не финальная реалистичная 3D-игра.
- Установку и производительность нужно проверить на Xiaomi Pad 8.
